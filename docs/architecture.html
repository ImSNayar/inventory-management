Request / Data Flow
1
User selects filters
FilterBar.vue updates reactive refs in useFilters composable (warehouse, category, period, status)
2
Component watcher fires
Each view watches useFilters state; calls getCurrentFilters() to build query params object
3
Axios request to FastAPI
api.js sends GET to localhost:8001/api/… with filter params as query string
4
Backend filters in-memory data
FastAPI endpoint reads from pre-loaded Python lists, applies warehouse/category/status/month filters, validates via Pydantic
5
Response stored in component ref
Raw API data stored in ref() (e.g. allOrders, inventoryItems)
6
Computed properties derive display data
Charts, sorted tables, KPI values all derived as computed() — template re-renders reactively
